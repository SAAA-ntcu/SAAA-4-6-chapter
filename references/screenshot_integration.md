# 題本截圖與報告整合

原始資料夾包含各科題本 PDF、橫式答案 Excel、評量架構 PPTX 時，使用整合入口：

```powershell
python scripts/build_from_source.py --input-dir "桃園市七年級新生" --analysis-dir "桃園新生試題分析結果" --out-dir "驗證輸出"
python scripts/qa_verify.py --dir "驗證輸出" --analysis-dir "桃園新生試題分析結果" --json "驗證輸出/檢驗結果_AI產出.json"
```

整合入口預設產出六份 `_AI產出.docx`，涵蓋 C7N、M7N、E7N 的第四、六章。程式完全包含在 skill 內，不依賴研究資料夾或先前聊天產物。正式分析必須提供施測資料；只有明確指定 `--draft` 時，才允許將缺少的統計標成「待補」。

## 輸入與對應

- 各科子資料夾名稱：國語文、數學、英語文。
- 每科需唯一的 `*題本.pdf`、`*科答案.xlsx` 與評量向度 `.pptx`。多版本時先整理，程式不任選第一份。
- 分析目錄提供 `<C|M|E>7N_試題分析總表.xlsx`；同目錄的 `*7N_分析結果.xlsx` 沿用原引擎的高精度計算。
- 正式答案讀取橫式表格的實際題號；向度讀取 PPTX 的分布表並保留來源投影片／列號。正式答案與統計答案不符、缺向度、重複題號或缺圖時停止。
- `M7N題號答案調整` 是歷史題號對照，不拿其中的舊難度冒充本次施測統計。
- 7N 的施測年級為七年級新生，內部試題碼依原規範使用六年級課程碼，例如 `115-C6-A1-01`。以題號而非檔案排序配圖，國語文依向度重排時仍可對上正確圖片。

## 圖片規則

`question_screenshots.py` 處理分欄、頁尾、題組、白邊及國語文封閉文字框。框線高於題號時，一起上移本題與前題的切分位置，保留完整文字框並排除前題碎線。四邊端點容許原稿的細微錯位。

純數字頁碼僅在頁面底部中央辨識，避免把數學分數的分子／分母當成頁碼而切掉選項。共用材料依來源解析度限制放大，只有題組編號的聽力材料不放大成滿頁文字。

國語文未註明題組範圍的獨立文章頁，依文章頁、續文及後續題號建立材料關聯；保留待確認標記。依使用者要求，國語及英文共用文章先合併全部來源頁／段落，再等比例調整至同一報告頁內。不得裁掉續文或分段內容。文章每題組插入一次，放在首次相關小題之前；題組跨向度排序時，以報告中首次出現的小題為準。

題目圖片置於第四章第 4 列的「題目」欄，使用與文字排列的等比例圖片。**不要逐張拉滿欄寬**：白邊裁除後的圖片寬度差異不代表字級差異。`image_layout.py` 依 PDF 題幹字元加權眾數推估主字級，英文目標 13pt，其他科目目標約 11pt；同一科所有題圖採同一個來源倍率。過寬或過高的題圖會共同限制全科倍率，不再讓短題放大、長題單獨縮小。來源無文字層時採原尺寸作為共同基準，並在對照檔記錄 fallback 供人工檢查。這只一致化嵌入倍率，保留原題本內標題、註解與圖中字體的相對大小。

共用文章採獨立的整頁縮放倍率，依實際可用頁寬／頁高扣除標題及安全空間後取最小倍率；可放大至整頁，但不改變長寬比。一般題圖維持各科共同倍率。文章使用無框單格表格；國語、英語的共用文章在扣除標題後的單頁文章區域垂直置中，水平維持靠左。一般題圖維持靠左、靠上。僅有題組編號的聽力材料維持原題目欄位置，不視為整頁文章。分頁段落與文章標題關閉 snapToGrid，避免文件格線把標題與文章擠成兩頁。僅有編號的聽力題組放在第一個小題的題目欄，不另佔空頁。`.images.json` 記錄來源主字級、目標字級、實際倍率、有效字級、顯示尺寸、合圖全部來源段落及 SHA256；QA 檢查 Word 的圖片、來源與對齊設定，實際 PDF 檢查文章標題和整張合圖同頁及尺寸。

題圖不保留來源題號：以 PDF 字元座標只移除本題開頭的數字與標點，再裁白邊；保留題幹中的數字、選項、圖框與文章。`exclude_rects` 記錄排除座標，`question_number_removed` 記錄題號移除結果，方便逐題核對。

國語題尾若夾入框外、獨立成行的下一大題標題（例如「二、閱讀理解題」），在該標題上方截止；保留最後選項及完整文章。文章框內的同名文字不可排除。`excluded_section_heading` 記錄標題原文、位置及原裁切底界。此規則只處理題圖裁切，不調整分析尾段的跨頁策略。

取消圖片列的固定列高。分析區依三個章節整理成外觀連續的列，取消整列鎖頁與 keepNext 造成的整塊跳頁；「一、試題分析」以下所有說明段落採固定行高 24pt（OOXML `line=480`、`lineRule=exact`），保留原字級，移除多餘空白占位段落。每題只在表格外插入明確分頁符號，避免相鄰試題表格被 Word 合併。取消段落的 keepNext、keepLines 與 pageBreakBefore 旗標，避免 Word 顯示編輯標記時在左側出現黑色方點。選答率後立即接試題分析；長題允許自然續頁。保留學習重點與專家質性分析原有內容，不自動撰寫專家判讀。

英語文截圖僅使用題本中實際存在的文字與圖像。MP3 不等於經確認的聽力稿；未提供逐字稿時不自行補造。
聽力最後一題後的「聽力試題已播音完畢，下一大題開始為閱讀測驗」與翻頁作答提示屬考場指示，截圖在提示前截止，不能併入題圖。保留最後一題的全部選項，排除位置記錄於 `excluded_exam_instruction`。

## 國語布局範例的適用範圍

使用者提供的圖片只作布局參照，不改原本前言、年級、答案／選項標示、評量目標及知識向度。不得從範例複製細項、插入「待補」或加括號文字；版面依圖片調整：語文知識、閱讀理解的引言各接在首題表格之前，分頁放在整組引言之前，避免引言獨占一頁；兩段評量說明均採左縮排840 twips、首行480 twips、固定24點行高。保留範本既有表格欄寬及分析段落縮排。各科一般題圖靠左、靠上；國語、英語整頁共用文章另採垂直置中、水平靠左；維持共同倍率、完整文章單頁及分析固定24點等已確認規則。

## 既有標準化資料入口

```powershell
python scripts/generate_reports.py --ans-file C7N_ans.xlsx --analysis-file C7N_試題分析總表.xlsx --subject C --grade 7N --booklet-pdf 題本.pdf --out-dir 輸出 --output-suffix _AI產出
```

若已截圖，可改用 `--images-manifest 路徑/manifest.json`；與 `--booklet-pdf` 擇一。單一題本不套用到多科 auto-scan。原本沒有提供題本的流程仍可產出留白題目欄。

## 檢驗與交付

每份第四章有 `.images.json` 圖片對照檔，記錄來源 PDF、頁碼、裁切座標、試題代碼及 PNG SHA256。QA 檢查 Word 內每題恰有一張正確圖片，雜湊與截圖一致；共用文章全部來源段落合成後恰好插入一次。另輸出各科來源檔雜湊與答案／向度來源格位，方便追溯。

機器檢驗不取代版面檢查。DOCX 需轉 PDF／逐頁 PNG，檢查表格、圖片、文章續頁與頁碼，尤其注意大圖及長題。Windows 沒有 LibreOffice 時，可使用獨立隱藏 Word 執行個體：

第六章國語文與英語文的列高採「至少」，讓長題號清單及次向度名稱完整換行；數學／自然同一向度的高、全、低三列一起移頁。檢查時須確認題號清單真的出現在 PDF 中，不能僅確認 DOCX 內的儲存格文字存在。

```powershell
./scripts/render_word.ps1 -InputPath "輸出資料夾" -OutputDirectory "QA暫存資料夾"
python scripts/verify_pagination.py --dir "輸出資料夾" --pdf-dir "QA暫存資料夾" --json "輸出資料夾/分頁檢驗_AI產出.json"
```

這只將明確指定的 DOCX 以唯讀方式轉為 QA PDF，不修改原範本，不控制使用者現有的 Word 視窗。最終交付仍以 `_AI產出.docx` 為主，QA PDF 為內部檢查檔。
